# Business Logto Sign-in Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a direct, branded, business-only Logto sign-in flow that returns authenticated owners to `/panel/profile` without the current intermediate screen.

**Architecture:** The Tik Profil Next.js entry route will decide between immediate OIDC handoff and a small recovery state. Logto branding will be generated by a tested, deterministic module and applied through the existing Management API credentials, with the previous configuration captured before mutation. Authentication remains Authorization Code + PKCE and PostgreSQL memberships remain authoritative.

**Tech Stack:** Next.js App Router, React, TypeScript, Node test runner, Logto Management API, Tailwind CSS, Browser plugin.

## Global Constraints

- Business authentication stays on Logto Authorization Code + PKCE.
- Normal `/giris-yap` entry performs one immediate document-level handoff.
- Authentication errors and logout results must not create redirect loops.
- Visual tokens are `#FFB347`, `#F6A52F`, `#FAF8F4`, `#FFFFFF`, `#211A12`, `#6F665C`, and `#E7DED3`.
- The hosted business form exposes identifier, password, password visibility, and one primary sign-in action.
- Registration, Google sign-in, technical database copy, and canary copy are not visible in the business flow.
- Customer Netgsm/native Google authentication is unchanged.
- Existing business aliases are not renamed in this rollout.

Build `URLSearchParams` from the normalized callback. Return recovery whenever an auth error exists or logout equals `success`; otherwise return redirect.

```ts
export function resolveBusinessLogtoEntry(input: BusinessLogtoEntryInput): BusinessLogtoEntry {
  const callbackUrl = normalizeLogtoRedirectPath(input.callbackUrl, "/panel/profile");
  const params = new URLSearchParams({ actor: "business", callbackUrl });
  const retryHref = `/api/auth/logto/sign-in?${params.toString()}`;
  if (input.authError || input.logout === "success") {
    return { kind: "recovery", authError: input.authError ?? null, loggedOut: input.logout === "success", retryHref };
  }
  return { kind: "redirect", href: retryHref };
}
```
